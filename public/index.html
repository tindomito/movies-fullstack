🎬 Movies API

API RESTful para gestión de películas y directores con autenticación JWT

🔐 Autenticación

POST /api/auth/register
Registrar nuevo usuario
POST /api/auth/login
Iniciar sesión
GET /api/auth/profile
Obtener perfil del usuario
🔒 Requiere autenticación
curl -X POST http://localhost:3000/api/auth/register \ -H "Content-Type: application/json" \ -d '{ "username": "usuario", "email": "usuario@email.com", "password": "password123" }'

🎥 Películas

GET /api/movies
Obtener todas las películas (con filtros y paginación)
GET /api/movies/:id
Obtener película por ID
GET /api/movies/search?q=título
Buscar películas por título
GET /api/movies/genre/:genre
Filtrar películas por género
POST /api/movies
Crear nueva película
🔒 Requiere autenticación de administrador
PUT /api/movies/:id
Actualizar película
🔒 Requiere autenticación de administrador
DELETE /api/movies/:id
Eliminar película
🔒 Requiere autenticación de administrador
curl -X GET "http://localhost:3000/api/movies?genre=accion&year=2023&page=1&limit=5"

🎭 Directores

GET /api/directors
Obtener todos los directores (con filtros y paginación)
GET /api/directors/:id
Obtener director por ID (incluye sus películas)
GET /api/directors/search?q=nombre
Buscar directores por nombre
GET /api/directors/nationality/:nationality
Filtrar directores por nacionalidad
GET /api/directors/stats
Obtener estadísticas de directores
POST /api/directors
Crear nuevo director
🔒 Requiere autenticación de administrador
PUT /api/directors/:id
Actualizar director
🔒 Requiere autenticación de administrador
DELETE /api/directors/:id
Eliminar director
🔒 Requiere autenticación de administrador
curl -X GET "http://localhost:3000/api/directors/search?q=Spielberg"

⚙️ Filtros y Parámetros

Parámetros de Películas:

  • genre - Filtrar por género (separados por coma)
  • year - Filtrar por año
  • minRating - Calificación mínima
  • maxRating - Calificación máxima
  • director - ID del director
  • search - Búsqueda de texto completo
  • page - Número de página (default: 1)
  • limit - Elementos por página (default: 10)
  • sortBy - Campo para ordenar (title, year, rating, etc.)
  • order - Orden: asc o desc

Parámetros de Directores:

  • nationality - Filtrar por nacionalidad
  • isActive - Filtrar por estado activo (true/false)
  • search - Búsqueda por nombre
  • page - Número de página
  • limit - Elementos por página
  • sortBy - Campo para ordenar
  • order - Orden: asc o desc
# Películas de acción del 2023 con rating > 7 curl -X GET "http://localhost:3000/api/movies?genre=accion&year=2023&minRating=7" # Directores argentinos activos curl -X GET "http://localhost:3000/api/directors?nationality=Argentina&isActive=true"

📋 Ejemplos de Uso

1. Registrar usuario y obtener token:

# Registro curl -X POST http://localhost:3000/api/auth/register \ -H "Content-Type: application/json" \ -d '{ "username": "admin", "email": "admin@movies.com", "password": "admin123" }' # Login curl -X POST http://localhost:3000/api/auth/login \ -H "Content-Type: application/json" \ -d '{ "email": "admin@movies.com", "password": "admin123" }'

2. Crear un director:

curl -X POST http://localhost:3000/api/directors \ -H "Content-Type: application/json" \ -H "Authorization: Bearer TU_TOKEN_JWT" \ -d '{ "name": "Steven", "lastName": "Spielberg", "birthDate": "1946-12-18", "nationality": "Estadounidense", "biography": "Director legendario de Hollywood...", "awards": [ { "name": "Oscar", "year": 1994, "category": "Mejor Director" } ] }'

3. Crear una película:

curl -X POST http://localhost:3000/api/movies \ -H "Content-Type: application/json" \ -H "Authorization: Bearer TU_TOKEN_JWT" \ -d '{ "title": "Jurassic Park", "director": "DIRECTOR_ID_AQUI", "year": 1993, "genre": ["Ciencia Ficción", "Aventura"], "duration": 127, "rating": 8.1, "synopsis": "Un parque temático con dinosaurios...", "budget": 63000000, "boxOffice": 1029153882 }'

📊 Códigos de Respuesta

✅ 200 OK - Solicitud exitosa
✅ 201 Created - Recurso creado exitosamente
⚠️ 400 Bad Request - Error en los datos enviados
🔒 401 Unauthorized - Token inválido o faltante
🚫 403 Forbidden - Permisos insuficientes
❌ 404 Not Found - Recurso no encontrado
💥 500 Internal Server Error - Error del servidor

Ejemplo de respuesta exitosa:

{ "success": true, "message": "Película creada exitosamente", "data": { "_id": "64a7b2c3d4e5f6789012345a", "title": "Jurassic Park", "director": { "_id": "64a7b1c2d3e4f5678901234b", "name": "Steven", "lastName": "Spielberg" }, "year": 1993, "genre": ["Ciencia Ficción", "Aventura"], "duration": 127, "rating": 8.1, "createdAt": "2023-07-07T10:30:00.000Z" } }

Ejemplo de respuesta con error:

{ "success": false, "message": "Errores de validación", "errors": [ { "field": "title", "message": "El título es obligatorio" }, { "field": "year", "message": "El año debe ser posterior a 1900" } ] }
